# TrustPay 데모 발표 스크립트

## 데모 준비

```bash
# 1. DB 초기화 및 시드 데이터 생성
cd apps/api
DATABASE_URL="file:./dev.db" npx prisma db push
DATABASE_URL="file:./dev.db" npm run seed

# 2. 서버 시작 (데모 모드)
DEMO_MODE=true DATABASE_URL="file:./dev.db" pnpm dev

# 3. 모바일 앱 시작 (별도 터미널)
cd apps/mobile && pnpm start
```

## 데모 플로우 (5분)

### Scene 1: 문제 제기 (30초)
> "매년 수천 건의 선불 결제 피해가 발생합니다.
> 헬스장이 폐업하면? 미용실 쿠폰이 남았는데 문을 닫으면?
> 소비자는 돈을 잃고, 법적 분쟁만 남습니다."

### Scene 2: 소비자 로그인 (30초)
1. 모바일 앱 실행
2. **Consumer** 선택 → 전화번호 `010-2000-0001` 입력
3. 로그인 → "김민수" 대시보드 진입
4. 에스크로 3건 표시:
   - 파워짐 피트니스 (진행중, 3/6 릴리즈)
   - 강남 블루보틀 (완료, 3/3 릴리즈)
   - 헤어살롱 루나 (취소됨, 1/4 릴리즈 후 환불)

> "소비자 김민수의 대시보드입니다. 세 가지 상태를 모두 볼 수 있습니다.
> 진행중인 헬스장 에스크로는 3개월치가 지급되었고,
> 나머지 3개월치는 XRPL 블록체인에 안전하게 보관 중입니다."

### Scene 3: 새 에스크로 생성 (1분)
1. **+** 버튼 탭 → 사업자 선택 화면
2. "정상어학원" 선택
3. 금액: `300` RLUSD, 기간: `3`개월 입력
4. 에스크로 생성 → 월 100 RLUSD × 3회 분할

> "학원 3개월 선불 300 RLUSD. XRPL Token Escrow가 매월 100 RLUSD씩
> 자동으로 분할 보관합니다. XLS-85 — XRPL의 최신 기능입니다."

### Scene 4: 사업자 정산 (1분)
1. 로그아웃 → **Business** 전환
2. `010-1000-0002` (파워짐 피트니스) 로그인
3. 대시보드: 수령액/대기액 확인
4. 릴리즈 버튼 → Month 4 릴리즈 실행

> "사업자는 매월 약속된 금액을 청구합니다.
> XRPL이 FinishAfter 시간을 확인하고 RLUSD를 전송합니다."

### Scene 5: 소비자 보호 — 환불 (1분)
1. 로그아웃 → Consumer로 다시 로그인 (`010-2000-0001`)
2. 에스크로 상세 → 취소 버튼
3. 남은 pending 엔트리만 환불, 이미 released된 건 유지

> "만약 사업자가 폐업하면? 소비자는 남은 금액을 환불받을 수 있습니다.
> 이미 이용한 달은 사업자에게 지급 완료, 미이용분만 돌려받습니다.
> 중재자 없이, 블록체인 에스크로 구조로 처리합니다."

### Scene 6: 기술 요약 (1분)
> "TrustPay는 XRPL의 Token Escrow(XLS-85)를 활용합니다.
>
> - RLUSD 스테이블코인으로 가치 변동 없이 안전한 결제
> - 시간 기반 에스크로로 매월 정산
> - 소비자 보호: CancelAfter 이후 환불 가능
> - 모든 거래가 XRPL 온체인에 투명하게 기록
>
> 선불 결제의 신뢰 문제를 블록체인으로 해결합니다."
